# Left Menu

The left menu is grouped into collapsible sections by default. Each person only
sees the links their role allows, and a section with nothing in it for that
person is not shown.

| Position | Entry |
| --- | --- |
| Top | Dashboard, Search, Notifications, Chat |
| Support | Tickets, Issue tracker, Service status, Knowledge base, Documentation search, Forms, Help |
| Sales & Billing | Shop, Quotes, Orders, Invoices, Subscriptions, Marketing |
| Office 365 | Office 365 tools (unchanged) |
| Assets & Network | Assets, Network Devices, IPAM, Racks, Websites, Expirations |
| Company | Staff, Processes, Shared credentials, Voice Monitor |
| Security & Compliance | Compliance, Compliance Checks, Continuity, Windows Defender, DMARC reports |
| Reports | Reports, Reporting, Backup Summary |
| — | My Profile |
| Administration | Companies, Users, Roles, Sessions, Impersonation, Approvals, API Keys, Modules, Feature Packs, Tray Settings |
| Automation & AI | Scheduled Tasks, Schedule, Webhook Monitor, Message Templates, RAG Index, AI Quality, AI Tag Synonyms |
| Calls & Voice | Calls, Call Recordings, Voice Monitor settings |
| Logs & History | Backup History, Change Log, Audit Trail |

Sections open automatically when they contain the current page, and the menu
remembers which sections you opened in that browser. A collapsed section shows
the combined unread count of the links inside it, such as unread notifications.

## Customising the menu

Open **My Profile → Left menu** to change your layout:

- **Reorder** by dragging the handle on a row, or with the up and down arrows.
  If you move a link past a section with the arrows, it goes into that
  section. If you move it past the top or bottom edge of a section, it leaves
  the section.
- **Move to a section** with the "Move to" menu on each link.
- **Hide a link** with its switch. My Profile is always shown.
- **Create, rename or remove sections** with *New group*, the name field and the
  bin button. Removing a section keeps its links and moves them to the top
  level. Click a section's icon to choose a different icon.
- Add **dividers** and **spacers** to separate entries at the top level.
- **Reset to default** discards your saved layout after you confirm. That
  includes your sections, order and hidden links. The grouping shown above
  applies straight away. After a reset you follow the default, so later
  changes to the default layout reach you too.

## Upgrading

Everyone who has never saved a custom menu gets the grouped layout. Some people
saved a menu before groups existed, so it holds only an order and hidden links.
Those people get the grouped layout too, and the links they hid stay hidden.
Menus that already contain custom groups are kept exactly as they were saved.
