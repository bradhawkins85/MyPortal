Seeing Delete or Discard? How to keep and run the installer

For an uncommon or unrecognised download warning, use the steps below to keep the MyPortal Tray installer requested by your IT team. Select an image to view it full size.

Microsoft Edge

  1. Open Downloads from the browser toolbar, or press Ctrl + J.
  2. Find the MyPortal Tray .exe download. If Edge offers Delete, open the three-dot menu (More actions) beside the file and choose Keep.
  3. If a confirmation appears, select Show more, then Keep anyway.
  4. Wait for the download to finish, then choose Open file.

Google Chrome

  1. Open Downloads from the browser toolbar, or press Ctrl + J.
  2. Find the MyPortal Tray .exe download. If Chrome offers Delete, Delete from history, or Discard, open the warning details or the file's menu. Choose Keep and confirm Keep anyway if asked. Newer Chrome versions may show Download suspicious file instead.
  3. Wait for the download to finish, then click the file name to open the installer. You can also open the .exe in your Windows Downloads folder.

Run the installer on Windows

If Windows displays Windows protected your PC for an unrecognised app, select More info. Check that the app and publisher match what your IT team expects, then select Run anyway if available.

Follow the installer prompts to finish setup.

Images are illustrations; wording can vary by browser and Windows version. If the file was already deleted, download it again from this page.

If the warning reports malware or a virus, or your organisation blocks the app or offers no Keep / Run anyway option, contact your IT team.
