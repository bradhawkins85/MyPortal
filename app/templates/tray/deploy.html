    Set up a new Windows computer

    Use this package only for a new or reset Windows 11 Pro, Enterprise or Education x64 computer during initial setup. It creates a local administrator named ProvisioningAdmin, completes initial setup and installs MyPortal Tray, with any Wi-Fi, PC naming and directory join settings selected by your IT team.

    Download provisioning package (.ppkg)

    1. On another computer, download the package and copy the .ppkg file to the root of a USB drive.
    2. Turn on the new computer and insert the USB drive at the first Windows setup screen. If provisioning does not appear, press the Windows key five times.
    3. Select the package if asked, confirm the package is from your IT team, and enter the package unlock password provided separately by IT.
    4. Leave the USB drive connected until provisioning finishes. Windows may restart. Sign in using the ProvisioningAdmin account password supplied by IT; the tray icon starts after sign-in.

    The package unlock password and account password are different. Internet access is needed to register with MyPortal or join Microsoft Entra ID. If IT configured a local domain join, connect to the organisation’s network so the PC can reach its domain controller and DNS. Your IT team can finish the remaining setup later.
