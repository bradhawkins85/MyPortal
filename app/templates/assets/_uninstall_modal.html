Agent maintenance

Uninstall agents

Remove the MyPortal Tray Agent and the MyPortal RMM agent from this device, with their services, files, settings and enrolment.

Runs first, with its default values, to clean up anything else on the device. The agents are removed only if it finishes with exit code 0; if it fails, times out or is aborted they stay installed.

The asset and its history stay in MyPortal; delete it afterwards if you no longer need it.
