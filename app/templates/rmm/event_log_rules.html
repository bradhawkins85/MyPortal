Rules

Rules check each event as a device sends it. Drop rules stop matching events being stored; use a drop rule's Run now to delete the matching events already stored. Other rules take their actions in the order you list them, in any combination: raise a ticket for the device's company with the device linked (while it is not closed, new matches on the device are added to it as internal updates), run scripts on the device that sent the event (at most once per cooldown on each device), or schedule scripts for later. Every condition of a rule must match.
