Rules

Rules check each event as a device sends it. Drop rules stop matching events being stored; use a drop rule's Run now to delete the matching events already stored. Script rules run an RMM script on the device that sent the event, at most once per cooldown on each device. Schedule rules run a script on the device later, after a delay or at a time of day. Ticket rules raise a ticket for the device's company with the device linked; while that ticket is not closed, new matches on the device are added to it as internal updates. Every condition of a rule must match.
