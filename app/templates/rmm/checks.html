Checks

Checks watch each device's disk space, ping targets, CPU, memory, services, network throughput, script results and check-ins. A problem must last the check's duration before the check fails. When it fails the check can run a script on the device or raise a ticket for it; the ticket gets an update when the check passes again. For the same drive, ping target, service, interface or script, a device's own check replaces its company's, which replaces a check for every company. Open a device to see its results and stats.
