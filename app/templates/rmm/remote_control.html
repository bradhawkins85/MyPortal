How it works

Technicians get a Connect button on each asset's Scripts card. It runs the activation script on the device through the RMM agent, then opens RustDesk or MeshCentral once the script reports back.

The activation script installs the tool when it is missing, otherwise resets its access password, then prints what MyPortal needs to connect. These lines are hidden from run history:

##myportal[session.id]=123456789        # RustDesk ID
##myportal[session.password]=one-time   # RustDesk password (optional)
##myportal[session.node_id]=node//abc   # MeshCentral node ID

Without an activation script, the device's ID is read from the asset custom field named below. Only scripts in the Common folder are offered, as they run on every company's devices.
