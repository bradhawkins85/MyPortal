How it works

Technicians get a Connect button on each asset's Scripts card. It runs the activation script on the device through the RMM agent, then opens RustDesk or MeshCentral once the script reports back.

The activation script installs the tool when it is missing, otherwise resets its access password, then prints what MyPortal needs to connect. These lines are hidden from run history:

##myportal[session.id]=123456789        # RustDesk ID
##myportal[session.password]=one-time   # RustDesk password (optional)
##myportal[session.node_id]=node//abc   # MeshCentral node ID

RustDesk works without a script of your own: MyPortal's built-in script applies RUSTDESK_CFG from the .env file, starts the RustDesk service, sets a new one-time password and reports the ID. Choose your own script to replace it. Without the RMM agent, the device's ID is read from the asset custom field named below. MeshCentral also works without a script of your own: its built-in script installs the agent on first use into a device group named after the device's company (so each company's devices sit in their own group, not one shared group), then finds the device's node by its host name and opens a signed-in link straight to it. Only scripts in the Common folder are offered, as they run on every company's devices.
