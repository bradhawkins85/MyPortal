How findings work

Every {{ settings_summary.interval_hours }} hours{% if not settings_summary.enabled %} (scheduled analyses are off){% endif %}, MyPortal compares the last 24 hours of every company's RMM data with the {{ settings_summary.baseline_days }} days before. Fixed rules raise the clearest problems{% if settings_summary.ai_enabled %}, then the signals go to {{ settings_summary.model or 'the configured AI model' }} for a best-guess assessment of anything else, such as links between them{% endif %}. Treat AI insights as leads to check, not conclusions.

{{ fx.icon('events') }}Event logs
Event types far more frequent than usual, and new ones appearing on several devices.
{{ fx.icon('security') }}Security
Account lockouts and the computers causing them, similar new accounts across devices or companies, new services, admin group changes and cleared logs.
{{ fx.icon('software') }}Software changes
Programs installed, removed or updated since the previous analysis, and event spikes that began where a program changed.
{{ fx.icon('performance') }}Performance
Devices using far more CPU or memory than devices with the same processor and memory.
{{ fx.icon('health') }}Device health
Nearly full system drives, long uptimes, silent agents and checks failing on many devices.

Acknowledge a finding when someone is on it, or dismiss it when it is expected; the same finding found again keeps your choice. Findings no longer detected stay for 90 days under Include no longer detected.
