How message templates work

Where templates are used and how variables are filled in.
  • Insert a template into an automation payload, SMS, ntfy notification or another template with {{ '{{ template.your-key }}' }} or {{ '{{ TEMPLATE_YOUR_KEY }}' }}.
  • Variables such as {{ '{{ user.first_name }}' }} or {{ '{{ ticket.number }}' }} are filled in from whatever sends the message. A variable with no value is left blank.
  • MyPortal's sign-up, staff invitation and renewal reminder emails look for templates with specific keys. Renaming or deleting one of those makes MyPortal send its built-in wording instead.
  • Variable values in HTML templates are escaped, but the template itself is sent exactly as written.

See the message template documentation for the full list of variables.
