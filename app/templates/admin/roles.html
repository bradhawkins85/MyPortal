How roles work

Access levels, system roles and least-privilege tips.

A role is a reusable permission set applied to company memberships. Each menu gets one access level. No access hides the menu and blocks its pages, APIs, downloads and workflow actions. Read only permits retrieval only. Read & write permits the actions the feature allows within record and company scope. View as role uses the same decision without the viewing administrator's bypass.

Tickets use No access, Own and All: Own opens /tickets for the user's tickets, while All opens /tickets for company tickets; technicians continue to use /admin/tickets for all customers. The Technician permission is a No / Yes switch.

System roles keep their names and can't be deleted, so baseline access policies stay intact; their permissions can still be tuned. A custom role can only be deleted once no company member holds it. Review roles regularly and record significant changes in your compliance records.
