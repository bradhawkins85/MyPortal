Install tokens

The tray installer (MSI or pkg) is given an install token when it is deployed. On first start each device swaps it for its own long-lived sign-in token.

macOS (bash) install snippet 
URL='{{ t.portal_url }}'
TOKEN='{{ t.new_token }}'
curl -fsSL "$URL/static/tray/myportal-tray.pkg" -o /tmp/myportal-tray.pkg
sudo /bin/sh -c "echo MYPORTAL_URL=$URL > /Library/Preferences/io.myportal.tray.env; echo ENROL_TOKEN=$TOKEN >> /Library/Preferences/io.myportal.tray.env"
sudo installer -pkg /tmp/myportal-tray.pkg -target /
