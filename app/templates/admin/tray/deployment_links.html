New deployment URL

A deployment URL is a private magic link to a ready-made tray installer for one company. Send it to the person installing; they open it, download the Windows installer or the macOS package and run it, and the device enrols into that company with no token to type. The installers are only served from this portal through the link, and they stop working when the link expires or is revoked.

Windows installers (EXE and MSI) are built and signed for each company by your Windows build server. They are rebuilt automatically when a new tray release is cached{% if release_tag %} (currently {{ release_tag }}){% endif %}. See Tray Build Server in the wiki to set one up.

Use {{ "{{ tray.deploymentUrl }}" }} in automations, ticket replies, canned responses, message templates and email signatures to insert the company's deployment URL. When a company has more than one active URL, the one that stays valid longest is used.

Shown only to admins. Defaults to the company name.

After this, the link and every package downloaded from it stop enrolling new devices. You can revoke any link early, including links with no expiry.
