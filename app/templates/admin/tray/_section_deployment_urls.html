Deployment URLs

A private link to a ready-made tray installer for one company. The person installing opens it, downloads the Windows installer or macOS package and runs it, and the computer enrols into that company with no token to type. Installers stop working when the link expires or is revoked.

New deployment URL

Shown only to admins. Defaults to the company name.

After this, the link and every package downloaded from it stop enrolling new devices. You can revoke any link early, including links with no expiry.

Your Windows build server builds and signs the EXE and MSI installers for each company, and rebuilds them when a new tray release is cached{% if dl.release_tag %} (currently {{ dl.release_tag }}){% endif %}. See Tray Build Server in the wiki to set one up.

Use {{ "{{ tray.deploymentUrl }}" }} in automations, ticket replies, canned responses, message templates and email signatures to insert the company's deployment URL. When a company has more than one active URL, the one that stays valid longest is used.
