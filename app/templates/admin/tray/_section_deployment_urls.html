Deployment URLs

A private link to ready-made tray installers for one company, with an optional provisioning package for new Windows computers. The computer enrols into that company with no token to type. Expiry or revocation stops downloads and new enrolment.

New deployment URL

Shown only to admins. Defaults to the company name.

After this, the link and every package downloaded from it stop enrolling new devices. You can revoke any link early, including links with no expiry.

Provision new Windows computers optional

For Windows 11 Pro, Enterprise or Education on x64 computers. The package completes initial setup, creates the local administrator ProvisioningAdmin and installs MyPortal Tray. It can also join Microsoft Entra ID (Azure AD) or your local Active Directory domain. The tray icon starts after sign-in.

Provisioning settings

Required for provisioning. Use 12–127 characters and at least three of uppercase letters, lowercase letters, numbers and symbols. Do not include ProvisioningAdmin. Store it securely; it will not be shown again. Rotate this shared bootstrap password or remove the account after provisioning.

Letters, numbers and hyphens, with one optional %RAND:n% for 1–15 random digits. The resulting name must fit in 15 characters. Local AD join requires a random token; a blank name uses MP-%RAND:8% for AD join. Other options keep the existing name when blank.

Up to 32 bytes. Leave blank to use Ethernet or connect to Wi-Fi separately.

WPA2-Personal, 8–63 printable ASCII characters. With an SSID, leave this blank only for an open network. Enterprise Wi-Fi is not supported.

The local ProvisioningAdmin account is created for every option. Choose one directory to join during setup.

Microsoft Entra ID join

Use Get Bulk Token in Windows Configuration Designer, save the project, and paste its Azure/BPRT value here. The token must be valid and unexpired; it is not a user password or an ordinary access token. MyPortal does not generate or renew it. The PC needs internet access during setup; tenant permissions and licensing requirements apply. Intune enrolment also requires your tenant’s automatic MDM enrolment configuration.

Use your tenant’s Microsoft public, US Government or China cloud authority. The default is the public cloud common authority.

Local Active Directory join

Use DOMAIN\user or a UPN. Delegate only the permissions needed to join computers in the intended location.

Distinguished name of the target OU. Leave blank to use the domain’s default computer location.

The PC must reach a domain controller and use working AD DNS during initial setup. This performs an online domain join; it does not provide a VPN or an offline domain join blob.

The encrypted package has a separate, generated unlock password, available to admins after the build finishes. Give that password to the person setting up the PC separately from the download link. A rebuild generates a new package password.

These settings are fixed for this URL; create a new URL to change them or replace an expired bulk token. Expiry or revocation cannot undo a downloaded package’s local account, Wi-Fi, PC name, directory join or initial setup changes.

Your Windows build server builds and signs the EXE and MSI installers for each company, and rebuilds them when a new tray release is cached{% if dl.release_tag %} (currently {{ dl.release_tag }}){% endif %}. See Tray Build Server in the wiki to set one up.

Use {{ "{{ tray.deploymentUrl }}" }} in automations, ticket replies, canned responses, message templates and email signatures to insert the company's deployment URL. Each company can have one active URL; companies that already have one are not listed. Revoke a company's URL to create a new one.
