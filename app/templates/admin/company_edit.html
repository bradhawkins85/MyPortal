          Variable Substitution

          Use variables in the description and quantity fields to dynamically populate invoice data. Wrap variable names in curly braces: {variable_name}.

          Standard variables:

          • {company_name} - Name of the company
          • {active_agents} - Count of assets synced within the last 30 days
          • {active_workstations} - Count of active Workstation-type assets
          • {active_servers} - Count of active Server-type assets
          • {active_users} - Count of active User-type assets
          • {total_assets} - Same as {active_agents}

          Asset custom field counts (checkbox fields only):

          • {cf_total_FIELDNAME} - Total assets where the checkbox field is ticked
          • {cf_active_FIELDNAME} - Assets synced within 30 days where the checkbox field is ticked

          Replace FIELDNAME with the custom field name, converting spaces, hyphens and other punctuation to underscores (consecutive separators collapse to a single underscore). For example: threatlocker-installed → {cf_active_threatlocker_installed}, and Bit Defender EDR → {cf_active_Bit_Defender_EDR}.

          Saved report variables: dynamic template variables such as {{ '{{ report.billable-assets.count }}' }} and {{ '{{ report.billable-assets.list }}' }} can be used where dynamic variables are supported. Reports can filter to the current invoice company with {{ '{{current.company}}' }} in the saved SQL.
