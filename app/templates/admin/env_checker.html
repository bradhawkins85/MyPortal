Server .env contents

Pasted content stays in browser memory. It is never sent to the server or saved by this tool. Clear it when finished.

Settings are grouped using this server's current module and feature pack state. Active settings come first, followed by disabled modules and packs, then stale content. Disabled settings stay uncommented and unchanged.

Values, comments, duplicate assignments and unrecognized content are preserved. Missing variables are reported without inserting values. This tool does not change the server's .env file.
