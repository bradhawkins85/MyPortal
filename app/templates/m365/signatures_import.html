Import from Outlook

Upload a ZIP file exported from Outlook to import an existing email signature. The imported signature will be identical to the Outlook version and is available for deployment and Classic Outlook sync immediately.

How to export from Outlook:
  1. Open Outlook and go to File > Options > Mail > Signatures.
  2. Select the signature you want to import.
  3. Click Export and save the .zip file.
  4. Upload that ZIP file here.

The ZIP should contain an HTML file, a TXT file, an RTF file, and a files/ folder with any embedded images.
