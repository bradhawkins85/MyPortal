Import from Outlook

Upload a ZIP file exported from Outlook to import an existing email signature. The imported signature will be identical to the Outlook version and is available for deployment and Classic Outlook sync immediately.

How to create the ZIP from Classic Outlook:
  1. Press Windows + R, enter %APPDATA%\Microsoft\Signatures and press Enter.
  2. Select the signature's .htm, .rtf and .txt files and its <name>_files folder.
  3. Right-click the selection and choose Compress to ZIP file (Windows 11) or Send to > Compressed (zipped) folder.
  4. Upload that ZIP file here.

The _files folder holds the signature's images; they are embedded in the imported signature. Signature ZIPs exported from new Outlook are also accepted.
