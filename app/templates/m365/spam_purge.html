Search scope

Purge type
HardDelete
Service limit
Up to 10 items/mailbox/action

Searches run against all Exchange locations in the selected company tenant. Holds and retention can preserve recoverable copies; this workflow does not bypass them.

How it runs: searches and purges use the Microsoft Graph eDiscovery API under the delegated sign-in of the Microsoft admin who last reconnected this company. That admin needs the eDiscovery Manager role group (search) and the Search And Purge role (purge) in Microsoft Purview. Searches are kept in the Purview eDiscovery case "MyPortal spam removal". If items remain after a purge, run the search and purge again.
