A computer with the RMM agent gets one health check a month, at a random day and time when its tray app is online, if it matches any group that is on. Each group applies to {{ company_label }} or to every company, and can be narrowed with the same advanced device rules as Checks: for example VIP company workstations, or computers whose operating system contains Windows 11. A month in which a technician already ran a health check is skipped.
